Το Flathub δεν είναι το μοναδικό repository για Flatpak. Είναι απλώς το μεγαλύτερο και πιο γνωστό.

Το Flatpak επιτρέπει να προσθέσεις διαφορετικές πηγές εφαρμογών (remotes), όπως ακριβώς συμβαίνει με τα repositories των παραδοσιακών διανομών Linux.

Μερικές εναλλακτικές είναι:

Υπάρχουν αρκετά. Τα σημαντικότερα που αξίζει να γνωρίζει η εφαρμογή σου είναι τα εξής:
Εναλλακτικά Flatpak repositories
Repository	Περιγραφή
Flathub	Το μεγαλύτερο γενικό αποθετήριο εφαρμογών
Flathub Beta	Beta και δοκιμαστικές εκδόσεις εφαρμογών
Fedora Flatpaks	Εφαρμογές που συντηρεί η κοινότητα Fedora
GNOME Nightly	Πειραματικές και υπό ανάπτυξη εφαρμογές GNOME
KDE Nightly	Δοκιμαστικές εκδόσεις εφαρμογών KDE
elementary AppCenter	Εφαρμογές του elementary OS
Endless OS	Εφαρμογές και εκπαιδευτικό λογισμικό

Τι θα πρότεινα για την εφαρμογή Slackware
Θα ήταν καλό να μην την περιορίσεις αποκλειστικά στο Flathub.

Να μπορεί να αναγνωρίζει όλα τα εγκατεστημένα Flatpak remotes με:
flatpak remotes --columns=name,url


Και να εμφανίζει τις εφαρμογές από κάθε repository με:
flatpak remote-ls --app


Έτσι θα έχεις έναν πραγματικό Flatpak Application Manager.
Πρόταση ονομασίας
Slackware Flatpak Manager

Το όνομα αυτό είναι πιο σωστό εάν σκοπεύεις να υποστηρίξεις πολλαπλά repositories και όχι μόνο το Flathub.

Μπορείς επίσης να δώσεις στον χρήστη τη δυνατότητα να προσθέτει και δικά του repositories. Το Flatpak υποστηρίζει αυτή τη δυνατότητα εγγενώς.
