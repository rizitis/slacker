## B. Exit codes

8. **Exit 2 is not documented.** clap usage errors (unknown command or flag) and the shell-glob case in `clap_error_exit` return 2. man, wiki Commands and ARCHITECTURE list only 0, 1, 20, 50, 100. The GUI shows 2 as an error.
9. **"Nothing to do" gives 0, 1 or 20 depending on the command.**
   - 20: search/info/file-search no match, `install` of an installed package, `upgrade` with nothing newer, `install-new` with nothing new, `clean-cache` empty, `history NAME` with no events, install/remove-template with nothing to do, `revert-pkg` with no previous versions, `slacker install` with no arguments.
   - 1: install/reinstall/remove/download of a name that matches nothing (`abort_on_misses`), `show-changelog` of an unknown repo, `install-template` of an unknown template.
   - 0: `upgrade-all` "Everything is up to date", `clean-system` no foreign packages, `new-config` no .new files, `trust-repo` of a repo that is not quarantined.
   - The man page defines 20 as "No package was found to act on".
10. **`check-updates` exits 0 when a repo is unknown or unreachable** (on purpose, per the code comment). A script cannot tell "all up to date" from "could not check".
11. **New in 0.14.1:** with an inconsistent cached PACKAGES.TXT, `check-updates` exits 100 (0.14.0: 0) and `install` exits 1, refused (0.14.0: 0, installed). Not in the docs.
